01 Choisir sa version

Deux versions.
Une même idée.

Installez l’application Android, ou ouvrez Lectura Web en un clic. Choisissez ce qui vous convient.

Application native

Android (APK)

Pour Android 12 et plus. Application native, 43 personnages, voix HD hors ligne.

Télécharger au format ZIP Télécharger directement (APK)

Extrayez le ZIP, puis ouvrez Lectura.apk.

Dans le navigateur

Web (PWA)

Pour Windows, Linux, macOS et Android. Fonctionne dans le navigateur, installable en un clic sur les navigateurs compatibles.

Ouvrir Lectura Web

Accessible depuis la page d’accueil, sans télécharger d’APK.
