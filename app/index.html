Installation

Cette version nécessite Android 12 ou une version ultérieure.

  1. Télécharge l’APK, puis ouvre-le depuis les téléchargements de ton appareil.
  2. Si Android le demande, autorise l’installation pour l’application qui a ouvert le fichier. Tu peux retirer cette autorisation après l’installation.
  3. Pour mettre à jour une installation Lectura portant le même certificat, installe l’APK sans désinstaller la version existante.
